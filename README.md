# Calidad de Software - Proyecto ACA

Aplicativo web educativo sobre Calidad de Software que incluye normas, modelos, estándares y evaluación práctica.

## Contenido

- Introducción a Calidad de Software
- Normas ISO (25010, 9126, 27001, 12207)
- Modelos de Calidad (CMMI, MOPROSOFT, SPICE, Six Sigma)
- Estándares de Desarrollo
- Código y Buenas Prácticas (Principios SOLID)
- Pruebas y Evaluación
- Evaluación de Sistema de Gestión Académica (4.4/5.0)
- Conclusiones y Recomendaciones

## Cómo usar

Abre el archivo `Aca calidad del software.html` en tu navegador.

## Tecnologías

HTML5, CSS3, Bootstrap 5, JavaScript
